# スターと（低ポリゴン版・ためし）

2D 版（[START](https://github.com/chisatot1029-droid/START)）の画面を、低ポリゴンの 3D で作り直した試作です。
シナリオ最新版の **場面1**（何もない部屋 → 広い部屋 → 怪盗の家の前 → 家に入るまで）を遊べます。

`index.html` を Chrome / Safari で開くと遊べます（3D の部品とフォントをネットから読むので、インターネットが必要です）。

## 操作
- ↑ ↓ ← →（または W A S D）・ゆびで なぞる：あるく
- クリック / タップ / Enter / スペース：セリフを すすめる
- 選択肢：クリック・タップ（または 数字キー 1・2・3）
- タイトルの「オートで みる」：ひとりでに すすむ（キー・クリックで とまる）

## ファイル
| ファイル | 中身 |
|---|---|
| `story.js` | セリフ・選択肢・できごとの順番（場面1）。書き方は先頭のコメント |
| `index.html` | 3D の世界・会話・オートモードの しくみ |
| `style.css` | 会話ウィンドウ・タイトル・セッティングの見た目（2D 版と同じ） |
| `assets/` | 会話ウィンドウの 顔アイコン（2D 版と同じ） |

## まだ 仮の所
- 警察（青い人）・怪盗（黄色い人）・人物A（赤い人）は 仮の 形
- 「主人公の一人称の動画」は まぶたが ひらく演出で 代用
- 音（BGM・効果音）は まだない
