# スターと（低ポリゴン版・ためし）

2D 版（[START](https://github.com/chisatot1029-droid/START)）の画面を、低ポリゴンの 3D で作り直した試作です。
シナリオ３（書き込みシステム版）の **場面1**（ホーム画面の ナレーション → 何もない部屋 → 広い部屋 → 怪盗の家の前 → 家に入るまで）と
**場面2**（緑が多い暖かな家の中 → ケーキ → 屋根裏で 星を もらう まで）を遊べます。

`index.html` を Chrome / Safari で開くと遊べます（3D の部品とフォントをネットから読むので、インターネットが必要です）。

## 操作
- ↑ ↓ ← →（または W A S D）・ゆびで なぞる：あるく
- クリック / タップ / Enter / スペース：セリフを すすめる
- 選択肢：クリック・タップ（または 数字キー 1・2・3）
- タイトルの「オートで みる」：ひとりでに すすむ（キー・クリックで とまる）
- タイトルの「場面を選択」：場面1（はじめから）／場面2（怪盗の家に入るところから）を えらんで はじめる

## ファイル
| ファイル | 中身 |
|---|---|
| `story.js` | セリフ・選択肢・できごとの順番（場面1）。書き方は先頭のコメント |
| `index.html` | 3D の世界・会話・オートモードの しくみ |
| `style.css` | 会話ウィンドウ・タイトル・セッティングの見た目（2D 版と同じ） |
| `assets/` | 会話ウィンドウの 顔アイコン（2D 版と同じ） |

## 場面1 の 地図（「スターとマップ」より）
下から：目を覚ます 部屋 → 仕切り（まんなかに 出入口）→ 両わきに 植木の ある 長い 通路（とちゅうが バケモノの 場面）
→ 階段 → 柵に かこまれた 家の前の 広場（道の 両がわに 草木）→ アーチの ドアの 家。
地図の 数字は `story.js` の `map` に まとめて あります。

## 場面2 の 地図（「スターとマップ」より。単位は m）
- 1階：玄関 → 仕切り → 青い ラグ → ダイニング（机と 椅子 6つ）、右の 通路 → 階段・キッチン（L字の 台・コンロ・冷蔵庫・壁掛けの ナイフ・ケーキ）
- 屋根裏：階段を 上った 所 → 扉 → 部屋（本棚・窓・ローテーブル・座布団・布団）、部屋の 片隅に 屋上へ 出る 扉。登場人物に あわせて 地図の 半分の 広さに して、かたむいた 天井で 隠し部屋の ように
- ケーキは 回る 線を タップして 8こに 切る ミニゲーム

## キャラクターと 場面（Figma「claude用素材」より）
- 主人公：白い 四角い 頭・ヘッドホン・黒い リュック・大きな 赤い くつ。身長は 怪盗の 胸元くらい
- 怪盗（＝人物A）：白い からだ・黒い シルクハットと マント・長い 鼻・黄色い 目
- 警察に 変装した 怪盗：青い 制服と 帽子、目は 怪盗と 同じ 黄色。撃つ 時は 拳銃を かまえる
- リアオ（子供A・青い子・星を 持っている）／シィ（子供B・紫の子・屋根裏に 住む）：田野さんの デザイン画。会話の 顔アイコンは リアオ 4種・シィ 3種
- バケモノ：田野さんの デザイン画（頭巾を かぶった ような 幽霊の 形。すそと 背中は ぎざぎざ、つき出した 波うつ 唇、前は 目が 2つ、うしろに ひび）。怪盗と 同じくらいの 大きさで、口から 飲みこむ
- 「！」マーク：赤。いつも 見ている 人の ほうを むく
- 怪盗の家の前：灰色の 段々の 大きな 建物（怪盗が 通れる 高い ドア）、灰色の 広い 道、まだらの 野原。煙突の 煙・木・星空。主人公の ななめ うしろ から、遠くの 大きな 建物を 見る 角度

## 書き込む 欄（シナリオ３）
- 研究員の 質問や リアオへの 返事は、プレイヤーが 文字を 書き込む（「決定」で すすむ）
- 研究員の 相槌は、書いた ことばを 使って「そうだねぇ。〇〇なんだね。」と 返す（story.js の aizuchi）
- ケーキは「8個切る」か「好きな数を切る」（2〜16こ）を えらんで 切る
- 「自分で好きな数を食べる」「…。」を えらんだ 道は、家の 中を 歩いて 玄関か 2階へ。2階（屋根裏の廊下）は 製作中で おわる

## まだ 仮の所
- 研究員の カット：右下の わくに 田野さんの 研究員の 絵（スクリーンショットから 切りぬいた 仮の 画像）、セリフは 上の 吹き出し。メモを とる 仕草は 仮
- （家の中の 主人公は 田野さんの デザイン画の 変身した 姿：白い たまご形・首に ヘッドホン・羽の うで・黒い かばん・赤い くつ）
- 怪盗が 去る 裏口（1階の 奥の かべ）、屋根裏の 出口の 扉（左の かべ・布団の そば）
- 「②教えて欲しい」の セリフは シナリオに ないので「次に行く所を、教えて欲しい。」
- 「主人公の一人称の動画」は まぶたが ひらく演出で 代用
- 音（BGM・効果音）は まだない
